# SkillCraft Technology – Task 01: Excel Sales Dashboard

## Objective
Clean and analyze the Superstore sales dataset using Excel, and build a dashboard with Pivot Tables and Charts.

## Dataset
Global Superstore Dataset (Kaggle)

## Steps Performed
1. Cleaned the data (removed duplicates, formatted dates, created Month helper column)
2. Created Pivot Tables for Total Sales, Profit by Category, and Monthly Sales Trend
3. Built Profit by Category bar chart and Sales Trend chart
4. Applied conditional formatting to highlight high and low performers
5. Combined everything into a single Dashboard sheet

## Key Results
- Total Sales: 12,642,905
- Highest profit category: Technology (663,778)
